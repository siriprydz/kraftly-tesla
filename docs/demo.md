## Om något går fel

| Om                         | Då                                                                                                  |
| -------------------------- | --------------------------------------------------------------------------------------------------- |
| Prod svarar inte           | Gömda slides med skärmdumpar finns                                                                  |
| Inloggningen fungerar inte | Gömda slides finns                                                                                  |
| Nätet dör                  | Gömda slides. Bildspelet räcker för siffrorna.                                                      |
| Vi är efter i tid          | Smalna av sammanfattningen och “vad vi inte gjorde”. Behåll säkerhet, prestanda och tillgänglighet. |
